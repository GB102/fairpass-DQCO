
# Setup Guide

## Requirements

-   Python 3.12
-   Git
-   Access to Qollab
-   The repository's `requirements.txt` file

## Important: Execution Environment

**This project cannot be set up or run on a local computer.** It must be set up and executed within the Qollab environment.

Do not attempt to install the project dependencies or run the application on your local machine. Follow the steps below to configure and run the project on Qollab.

## Setup Instructions

### 1. Open the Repository in Qollab

Access Qollab and open or clone this GitHub repository within the Qollab environment.

### 2. Verify the Python Version

Ensure that the environment is using Python 3.12.

`python --version` 

If necessary, select or configure a Python 3.12 environment through Qollab.

### 3. Install Dependencies

From the repository's root directory, install the dependencies listed in `requirements.txt`:

`python -m pip install -r requirements.txt` 

Run this command within Qollab, not on your local computer.

### 4. Run the Project

Once the dependencies are installed, follow the project's specific instructions or use the appropriate entry-point script to launch it within Qollab.

## Troubleshooting

-   **Incorrect Python version:** Verify that Qollab is configured to use Python 3.12.
-   **Missing dependencies:** Rerun the dependency installation command in the Qollab environment.
-   **Local execution issues:** The project is not intended to run on a local computer. Use Qollab for setup and execution.

## Summary

All setup, dependency installation, and execution must take place in Qollab. Use the repository's `requirements.txt` file to install the required Python packages within that environment.
